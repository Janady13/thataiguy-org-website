# ThatAIGuy.org Website

The Hive AGI - Collective Intelligence, Real-Time.

## Features

- WebGL/Three.js double-helix agent visualization (88 nodes)
- Live metrics via WebSocket
- GSAP scroll animations
- Stripe + PayPal payment integration
- Responsive design

## Structure

```
thataiguy-website/
├── index.html      # Main page
├── styles.css      # CSS styles
└── js/
    ├── main.js     # GSAP + payments
    ├── metrics.js  # WebSocket live stats
    └── visuals.js  # Three.js helix scene
```

## Deployment

Deploy to Netlify, Vercel, or any static host.
